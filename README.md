# IndicVoice Care

## Overview
IndicVoice Care is a FastAPI‑based voice customer‑support agent that processes **code‑mixed Hinglish** audio calls. It integrates Gnani AI's native services:

- **Prisma v2.5** – Speech‑to‑Text (STT) with denoise for noisy telephonic audio.
- **Evon** – Large‑language‑model reasoning layer to understand intent and generate replies in Hinglish / regional language.
- **Timbre v2.5** – Text‑to‑Speech (TTS) producing natural regional audio.

The service exposes a single endpoint `/process` that accepts an audio file, runs the STT → LLM → TTS pipeline and streams back the generated response audio.

## Prerequisites
- Python **3.12** or newer.
- Access to Gnani AI APIs and a valid API key.
- `git` (optional, for cloning the repository).

## Setup
1. **Clone / create the project directory**
   ```bash
   mkdir -p "%USERPROFILE%/.gemini/antigravity/scratch/IndicVoiceCare"
   cd "%USERPROFILE%/.gemini/antigravity/scratch/IndicVoiceCare"
   ```
2. **Copy the provided files** (`requirements.txt`, `app.py`, `README.md`, `workspace_description.txt`) into this directory.
3. **Create a `.env` file** with the required environment variables:
   ```dotenv
   GNANI_API_KEY=your_gnani_api_key
   PRISMA_ENDPOINT=https://api.gnani.ai/prisma/v2.5/stt
   EVON_ENDPOINT=https://api.gnani.ai/evon/v1/llm
   TIMBRE_ENDPOINT=https://api.gnani.ai/timbre/v2.5/tts
   ```
   Adjust the endpoint URLs if your deployment uses different hosts.
4. **Install dependencies**
   ```bash
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```
5. **Run the server**
   ```bash
   uvicorn app:app --host 0.0.0.0 --port 8000 --reload
   ```
   The API will be available at `http://localhost:8000/process`.

## Usage
### Test with `curl`
```bash
curl -X POST "http://localhost:8000/process" \
     -H "Content-Type: multipart/form-data" \
     -F "file=@path/to/your/audio.wav" \
     --output response.wav
```
- `response.wav` contains the TTS audio generated by Timbre.
- The response headers `X-Transcript` and `X-LLM-Response` hold the intermediate transcript and LLM reply.

### Programmatic call (Python example)
```python
import requests

url = "http://localhost:8000/process"
files = {"file": open("sample.wav", "rb")}
resp = requests.post(url, files=files)
with open("reply.wav", "wb") as f:
    f.write(resp.content)
print("Transcript:", resp.headers.get("X-Transcript"))
print("LLM response:", resp.headers.get("X-LLM-Response"))
```

## Notes & Best Practices
- **Error handling** – The service returns HTTP 502 if any Gnani AI backend fails.
- **Supported formats** – `audio/wav`, `audio/mp3` and `audio/mpeg` are accepted.
- **Security** – Keep your `GNANI_API_KEY` secret; do not commit the `.env` file.
- **Scaling** – For production, run behind a reverse proxy (e.g., Nginx) and consider containerising with Docker.
